Web 前端开发实战 · 课程讲义

本讲义为 AI 实践课课堂用示例资料，用于“知识中心”页面的内容提炼。

第 1 章 HTML 语义化

HTML 负责网页的结构和内容。语义化是指根据内容的含义选择合适的标签，例如用 header 表示页头，nav 表示导航，main 表示主体内容，footer 表示页脚。

语义化的页面结构更清晰，便于搜索引擎理解，也能帮助屏幕阅读器等辅助工具正确读取内容。图片应通过 alt 属性提供替代文字。

第 2 章 CSS 布局

CSS 负责网页的样式和布局。常用的布局方式有两种：
1. Flexbox：适合一维布局，例如一行导航按钮或一列卡片；
2. Grid：适合二维布局，可以同时控制行和列，例如课程卡片网格。

盒模型是理解布局的基础，每个元素都由内容、内边距（padding）、边框（border）和外边距（margin）组成。

第 3 章 响应式设计

响应式设计让同一个页面能够适配电脑、平板和手机等不同屏幕。实现方式主要包括：
- 在页面头部设置 viewport 元信息；
- 使用百分比、fr 等相对单位，而不是固定像素宽度；
- 使用媒体查询（@media），在不同屏幕宽度下应用不同样式。

开发时可以使用浏览器开发者工具模拟不同设备进行检查。

第 4 章 JavaScript 基础

JavaScript 负责网页的交互逻辑。基础内容包括：使用 let 和 const 声明变量，数组和对象两种常用数据结构，以及函数的定义与调用。

数组的 map、filter、reduce 方法在处理数据时十分常用，分别用于转换、筛选和汇总数组中的元素。

第 5 章 DOM 与事件

DOM（文档对象模型）把网页表示为树状结构，JavaScript 可以通过它读取和修改页面内容。常用方法包括 querySelector 选取元素，textContent 修改文字。

addEventListener 用于监听用户操作，例如点击、输入和提交。处理表单提交时，通常需要调用 preventDefault 阻止页面刷新。

第 6 章 数据渲染

数据渲染是指根据数据动态生成页面内容。常见做法是把数据保存为数组，再遍历数组生成对应的 HTML 元素。

页面上的统计数字应由数据计算得出，而不是手动写死。这样数据更新后，页面会自动反映最新结果。

把用户输入或外部数据插入页面时，应对特殊字符进行转义，防止跨站脚本（XSS）攻击。

第 7 章 项目发布

前端页面开发完成后，需要发布到服务器上供他人访问。纯静态页面（只包含 HTML、CSS 和 JavaScript）不需要后端服务器，可以直接使用静态托管平台发布。

发布前应检查：所有链接和资源路径是否正确，页面在不同屏幕上是否正常显示，以及浏览器控制台中有无报错。

注意：直接双击打开本地 HTML 文件时，部分浏览器会限制读取同目录下的其他文件，正式发布后即可正常访问。
