Python 数据分析 · 课程讲义

本讲义为 AI 实践课课堂用示例资料，用于“知识中心”页面的内容提炼。

第 1 章 环境准备

Python 数据分析常用的工具包括：Python 解释器、Jupyter Notebook 交互式环境，以及 NumPy、pandas、Matplotlib 等第三方库。

可以使用 pip 安装所需的库，例如：pip install numpy pandas matplotlib。为了避免不同项目之间的依赖冲突，建议为每个项目创建独立的虚拟环境。

第 2 章 NumPy 基础

NumPy 提供了高效的多维数组对象 ndarray。与 Python 列表相比，数组中的元素类型一致，运算速度更快。

NumPy 支持向量化运算，即对整个数组直接进行加减乘除，而不需要逐个元素编写循环。常用函数包括 sum、mean、max、min 等。

第 3 章 pandas 数据结构

pandas 是 Python 中最常用的数据分析库，核心数据结构有两种：
1. Series：带索引的一维数据；
2. DataFrame：由行和列组成的二维表格，每一列可以是不同的数据类型。

使用 read_csv 函数可以把 CSV 文件读取为 DataFrame。读取后通常先用 head 查看前几行，用 info 查看字段类型和缺失情况。

第 4 章 数据清洗

真实数据往往存在缺失值、重复记录和格式错误，分析前需要先进行清洗。常见操作包括：
- 使用 isna 检查缺失值，用 dropna 删除或用 fillna 填充；
- 使用 drop_duplicates 删除重复记录；
- 使用 astype 转换字段类型，例如把文本转换为数字或日期。

需要注意：缺失值不等于 0。如果把缺失的成绩当成 0 分计算平均值，结果会被明显拉低。

第 5 章 分组与聚合

groupby 函数可以按一个或多个字段分组，再对每组进行聚合计算，例如求和、计数、平均值和最大值。

nunique 用于统计不重复值的个数。例如统计学生人数时，应对学生编号去重，而不是直接计算记录行数。

在分组前应先明确统计口径，即“一行数据代表什么”。口径不同，同一份数据会得出不同的结论。

第 6 章 数据可视化

Matplotlib 是 Python 最基础的绘图库，pandas 也可以直接调用它绘图。常见图表的选择原则如下：
- 比较不同类别的数值，用柱状图或条形图；
- 展示随时间变化的趋势，用折线图；
- 展示数值的分布情况，用直方图。

图表应包含标题、坐标轴标签和单位，避免使用过多颜色。

第 7 章 时间序列

处理日期数据时，先使用 to_datetime 把文本转换为日期类型，然后才能按日、周、月进行统计。

resample 函数可以按时间频率重新汇总数据，例如把每日数据汇总为每周数据。通过 dt.dayofweek 可以提取星期几，用于分析每周的活动规律。

第 8 章 综合案例

以学习记录分析为例，一个完整的分析流程包括：
1. 明确问题：例如哪门课程完成率最低；
2. 读取数据并检查字段、缺失值和重复记录；
3. 确定口径并完成分组、聚合计算；
4. 绘制图表，观察差异和趋势；
5. 得出结论，并提出可执行的建议。

结论应有具体数据支撑。使用 AI 生成分析代码后，应用独立方法（如电子表格）抽查关键结果。
