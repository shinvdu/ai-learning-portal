# 生产化路线图

> 本文用于评估 AI Learning Portal 从“演示 / 受控试点”走向“生产可用”还缺什么。
>
> 当前状态：**可作为单节点受控生产基线**。v1.2.0 已补齐邮箱验证、密码重置、MFA、账号锁定、审计、CSRF、版本化 migration、备份与生产模式；仍不具备 PostgreSQL/Redis 多实例、SSO、多租户、审计保留与完整可观测性，**不应直接作为公网 SaaS**。

## 0. v1.2.0 最小集完成情况

已完成：

- [x] 邮箱验证、忘记密码、单次令牌、重置后撤销会话；邮件通过 `MAIL_WEBHOOK_URL` 适配外部网关。
- [x] TOTP MFA + 一次性恢复码；账号页自助启停；管理员可重置 MFA。
- [x] 按账号锁定（5 次/15 分钟）与管理员解锁；登录/注册/验证/重置/MFA 接口按 IP 限流。
- [x] 审计日志：认证、密码/MFA、角色、课程/章节、学习记录、CSV 导入导出/重置；管理后台可查看。
- [x] CSRF 双提交 Cookie + 同源 Origin 校验；CSP 增加 `object-src` / `frame-src` / `worker-src` 等限制。
- [x] 版本化 SQLite migration（`schema_migrations`）。
- [x] `VACUUM INTO` 备份脚本与恢复文档。
- [x] 生产模式（`APP_ENV=production`）：不导入示例学习记录、要求邮件网关与显式管理员密码、不打印生成密码。
- [x] Nginx TLS/HSTS/限流示例、systemd 单元、`/healthz` 与 `/readyz`。
- [x] 管理员恢复脚本 `npm run admin:reset`。

仍未完成（下一阶段）：

- [ ] PostgreSQL 迁移与版本化 SQL down/rollback 策略。
- [ ] Redis 会话/限流与多实例无状态部署。
- [ ] 内置邮件供应商 SDK/SMTP（当前为 webhook 适配）；退信/重试队列。
- [ ] 审计日志保留、归档、导出与防篡改；登录告警。
- [ ] 强制管理员 MFA、SSO/OIDC/SAML、SCIM、多租户与资源级权限。
- [ ] Metrics/Tracing/Sentry、集中日志、告警与值班。
- [ ] CSP nonce（移除 `style-src 'unsafe-inline'`）、SAST/DAST、渗透测试。
- [ ] 隐私政策、数据保留/删除、DPA、内容版权确认。

## 1. 当前已有基础（不必重写）

- 参数化 SQL、CSV 导入校验与事务替换。
- 会话 Cookie（HttpOnly / SameSite=Lax）、scrypt 密码哈希、登录/注册限流。
- 密码重置撤销其他会话、停用用户撤销会话、最后一个管理员保护。
- 管理员/学员角色；原始学习记录与管理接口需要管理员。
- CSP、HTML 转义、请求体限制、同源 `Origin` 校验、视频 Range 请求。
- `npm run verify`（临时数据库）、CI 冒烟测试、响应式页面。
- 清晰的课程/章节/知识/看板代码结构与文档。

生产化应在这些基础上补齐，而不是推倒重来。

## 2. P0：未完成不能接真实用户

### 2.1 身份与账号体系

- [ ] 邮箱验证（注册后验证链接；未验证账号限制权限）。
- [ ] 忘记密码邮件 + 单次重置令牌（哈希存储、过期时间、一次性使用）。
- [ ] MFA（TOTP + 恢复码）；至少管理员强制开启。
- [ ] 按账号维度的登录失败锁定，而不只是按 IP 限流。
- [ ] 会话管理：设备列表、单设备下线、全部下线、异常登录提醒。
- [ ] 生产环境不把初始管理员密码打印到日志；改用 Secret Manager 或部署时一次性注入。
- [ ] 校内部署支持邀请注册或 SSO（OIDC/SAML），避免完全开放注册。

**验收标准**

- 新用户必须完成邮箱验证；重置密码链接只能使用一次且会过期。
- 管理员可查看并撤销自己的活跃会话；连续失败登录会按账号锁定。
- 初始管理员凭据不出现在普通运行日志中。

### 2.2 权限模型

- [ ] 从 `admin / learner` 扩展到教师、助教、课程负责人、只读审计员等角色。
- [ ] 资源级权限（例如“某门课的管理员”），至少为后续多课程/多院系预留。
- [ ] 高危操作（删除课程、删除记录、CSV 全量导入）要求二次确认、操作原因与审计。
- [ ] 增加只读模式 / 维护模式。

**验收标准**

- 每个写接口都能回答“谁能做、对哪个资源做、留下什么记录”。
- 高危操作有审计记录，能按操作者、时间、对象检索。

### 2.3 审计日志

- [ ] 不可变审计表：登录成功/失败、退出、密码重置、角色变更、启停账号。
- [ ] 课程、章节、视频、学习记录、CSV 导入/导出、数据重置。
- [ ] 记录操作者、角色、IP、时间、对象 ID、变更前后关键字段。
- [ ] 审计查询与导出；保留周期与归档策略。

**验收标准**

- 任何管理员数据变更都能追溯到人；审计日志不可通过普通管理员接口修改。

### 2.4 数据库与备份

- [ ] 版本化 migration（当前 `ensureColumn` 只是临时补列）。
- [ ] 生产数据与演示种子数据分离：生产环境只创建管理员，不导入示例学生。
- [ ] 备份与恢复演练；明确 RPO/RTO。
- [ ] 若继续 SQLite：单实例部署、WAL、定时备份、恢复验证。
- [ ] 若公网/多实例：迁移 PostgreSQL，连接池、索引、慢查询监控。
- [ ] 数据保留、删除、导出策略。

**验收标准**

- 能在预发环境从备份完整恢复一次，并记录耗时。
- 生产首次启动不包含任何示例学生数据。
- 数据库结构变更通过 migration 执行，可回滚。

### 2.5 安全边界

- [ ] 反向代理 + TLS + HSTS + WAF/DDoS 防护；应用只监听内网。
- [ ] CSP 去掉 `style-src 'unsafe-inline'`，改用 nonce/hash。
- [ ] 增加 CSRF Token（SameSite + Origin 已有一层，但生产建议双保险）。
- [ ] 密码哈希升级到 Argon2id（或提高 scrypt 参数），增加弱密码/泄露密码检查。
- [ ] 限流迁移到 Redis，支持多实例；管理员接口也限频。
- [ ] 密钥、SMTP、数据库密码进入 Secret Manager，定期轮换。
- [ ] CSV 导出防公式注入。
- [ ] 若增加文件上传：类型/大小/病毒扫描、对象存储隔离。
- [ ] SAST、依赖与运行时扫描、ZAP/DAST、渗透测试。

**验收标准**

- 外部扫描无高危/中危未修复项；安全头与 TLS 配置通过检查。
- 多实例下限流与登录锁定仍然有效。

### 2.6 可观测性与运维

- [ ] `/healthz`、`/readyz`。
- [ ] 结构化日志（请求 ID、用户 ID、耗时），不记录密码/令牌。
- [ ] Metrics（Prometheus）、Tracing（OpenTelemetry）、错误上报（Sentry）、告警。
- [ ] 容器化 + IaC + 预发/生产两套环境。
- [ ] 部署时执行 migration；零停机发布与回滚。
- [ ] 运行手册、值班与故障响应流程。

**验收标准**

- 登录失败、5xx、数据库异常、备份失败都有告警。
- 可在 30 分钟内完成一次回滚或恢复演练（目标可按组织调整）。

### 2.7 合规与法务

- [ ] 隐私政策、用户协议、Cookie/统计同意（如引入分析）。
- [ ] 真实学生数据属于个人信息：保留/删除/导出、访问审计、最小权限。
- [ ] 中国场景评估《个人信息保护法》（PIPL）；面向欧盟评估 GDPR；学校客户可能需要 DPA。
- [ ] 讲义、视频、品牌素材的版权与授权确认。
- [ ] 演示数据不得作为生产数据使用。

**验收标准**

- 能说明每类数据的来源、用途、保存期限、访问者、删除方式。
- 公开发布前完成内容与商标授权确认。

## 3. P1：正式上线前应完成

### 3.1 内容与媒资

- [ ] 知识中心编辑器：摘要、知识点、术语、FAQ、测验的增删改。
- [ ] 草稿 / 发布状态、版本记录、回滚。
- [ ] 章节拖拽排序、批量导入、发布状态。
- [ ] 视频上传到对象存储（S3/OSS）、转码 HLS、CDN、签名 URL。
- [ ] 移除对本地 `public/assets/*.mp4` 的生产依赖。
- [ ] CSV 大文件导入改为后台任务：进度、幂等、失败重试、导入报告。

### 3.2 性能与规模

- [ ] 课程、用户、学习记录、审计日志的分页与搜索。
- [ ] 看板聚合结果缓存或物化视图（当前每次全量计算）。
- [ ] 管理员课程列表不要返回全部章节正文。
- [ ] 压缩传输、HTTP 缓存策略、前端按需加载。
- [ ] 压测：登录、看板、CSV 导入并发场景。

### 3.3 质量保障

- [ ] 单元测试 + API 集成测试 + 浏览器 E2E。
- [ ] 覆盖：注册/登录/重置/MFA、权限边界、课程/章节编辑、CSV 导入、删除保护。
- [ ] 备份恢复与 migration 回滚演练。
- [ ] 可访问性 WCAG 2.1 AA、键盘导航、屏幕阅读器。
- [ ] 国际化（中/英）与浏览器兼容性回归。

### 3.4 产品体验

- [ ] 管理员批量操作、表格筛选/分页、内联编辑、操作历史。
- [ ] 学习者个人中心：我的课程、学习记录、测验结果。
- [ ] 当前用户与学习记录通过 `student_id` 脱钩，需要建立用户↔学员映射。
- [ ] 邮件/站内通知。

## 4. P2：规模化 / 企业化

- [ ] SSO（OIDC/SAML）、SCIM 自动开户。
- [ ] 组织/院系/租户隔离，多租户与数据分区。
- [ ] 数据驻留、读副本、独立媒体服务、队列。
- [ ] SLA、灾备（RTO/RPO）、审计导出、合规报表。
- [ ] 更细粒度 RBAC/ABAC、审批流。

## 5. 架构取舍

### 5.1 校内小规模（几十到几百人，单节点）

可以继续 SQLite，但必须满足：

- 单实例部署，WAL 模式。
- Litestream 或定时备份，定期恢复演练。
- HTTPS + 反向代理 + 基础 WAF/限流。
- 邮件验证、密码重置、MFA（至少管理员）、审计日志。
- 结构化日志与基本告警。

这可以称为“受控试点”，不是公网 SaaS。

### 5.2 公网 / 多学校 / 多租户

建议：

- PostgreSQL + Redis（会话、限流、缓存）+ S3/OSS + CDN + 后台任务队列。
- 应用无状态，可水平扩展；会话不落本地 SQLite。
- 视频转码与签名 URL；媒体独立服务。
- Fastify/Express + zod/TypeBox + Helmet + Pino（零依赖是 demo 约束，不必带到生产）。
- 管理后台仍可保留原生 JS，但建议 TypeScript + E2E；复杂度上升后再引入 Vue/React。

## 6. 建议实施顺序

1. 邮件验证/重置 + MFA + 审计日志 + 账号锁定 + Secret 管理。
2. PostgreSQL / 版本化 migration + 备份恢复 + 生产数据初始化。
3. HTTPS/代理/WAF + CSP/CSRF + Redis 限流。
4. 结构化日志、健康检查、Metrics、Sentry、容器化与 CI/CD。
5. 对象存储/CDN 视频、知识内容编辑器、后台导入任务。
6. E2E / 压测 / 安全测试 / 可访问性 / 合规文档。

## 7. 生产可用定义（Definition of Done）

- 真实用户可安全注册、验证、登录、找回密码、管理会话。
- 管理员操作可追溯、可审计、可回滚。
- 数据有备份、可恢复；migration 可回滚。
- 无高危安全漏洞；HTTPS、CSP、CSRF、限流、密码策略到位。
- 有日志、指标、告警、错误追踪与运行手册。
- 内容与媒体有合法授权与发布流程。
- 隐私、条款、数据保留/删除策略明确。
- 通过压测与一次完整的恢复演练。
