## 目标

复刻知识中心摘要、知识点、术语、FAQ、测验、人工修正与原文摘录。

## 行为与范围

- 课程切换与空状态。
- 3 题测验自动评分并展示解析/出处。
- 人工修正 before/after/note 区块。
- 原文摘录与讲义一致。

## 验收标准

- [ ] 5 门课知识内容完整。
- [ ] 测验答案与内容包一致。
- [ ] 无知识内容的课程显示空状态。
- [ ] 文本不使用 v-html 渲染。
