## 目标

提供用户、课程、章节与审计的管理界面。

## 行为与范围

- 用户表：角色、启停、改密、解锁、重置 MFA、标记验证。
- 课程表：编辑、删除（冲突时 force 二次确认）。
- 课程编辑器：元数据、课程级视频三态、章节 CRUD。
- 视频上传：课程/封面上传器（local 直传或 S3 预签名，含进度与预览），见 [F095](F095-admin-media-upload-ui.md)。
- 章节编辑器：标题、正文、章节视频三态（继承课程/自定义/关闭）与本章视频上传，见 [F096](F096-chapter-video.md)。
- 审计表：时间/操作者/动作/目标/IP；数据快照标签。

## 验收标准

- [ ] 管理员可完成全部管理操作，包括课程/章节视频与封面文件上传。
- [ ] 自己的角色/启停控件禁用。
- [ ] 删除冲突显示记录数并要求确认。
- [ ] 章节删除保留编号空洞提示。
- [ ] 章节列表显示视频模式标签；上传进行中不能保存表单。
