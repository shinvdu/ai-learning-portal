## 目标

在破坏性导入或重置前保存快照，并允许管理员恢复。

## 行为与范围

- 导入与重置前写入 record_snapshots（行数 + JSONB 行集）。
- 记录 dataset_imports 结果（插入/跳过/错误）。
- 管理端可列出快照并恢复到指定快照。
- 恢复操作写审计并保留当前快照。

## 验收标准

- [ ] 导入后可看到前后两个快照。
- [ ] 恢复后指标精确回到快照时点。
- [ ] 恢复本身也可回滚。
- [ ] 快照包含 course_name 解析结果。
