## 目标

提供忘记密码、令牌重置与登录后修改密码，并正确撤销会话。

## 行为与范围

- 忘记密码始终返回通用成功，仅对活跃用户发 1 小时令牌。
- 重置后标记邮箱已验证、撤销全部会话、令牌单次使用。
- 修改密码需当前密码，撤销其他会话但保留当前。
- 新密码沿用 8–200 字符策略。

## 验收标准

- [ ] 重置链接过期或复用被拒绝。
- [ ] 重置后旧会话全部失效。
- [ ] 修改密码后当前会话仍可用、其他会话失效。
- [ ] 忘记密码不泄露邮箱是否存在。
