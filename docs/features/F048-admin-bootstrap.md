## 目标

首次启动创建管理员，并防止系统失去最后一个可用管理员。

## 行为与范围

- 无活跃管理员时按 ADMIN_EMAIL/ADMIN_PASSWORD 创建或提升。
- 生产缺少 ADMIN_PASSWORD 则启动失败；不打印生成密码。
- 禁止降级或停用最后一个活跃管理员。
- 禁止自降级/自停用；停用撤销该用户会话。

## 验收标准

- [ ] 空库启动后有且仅有一个管理员。
- [ ] 生产缺密码启动失败。
- [ ] 最后管理员降级/停用被拒绝。
- [ ] 并发互降级时至少保留一个（advisory lock）。
