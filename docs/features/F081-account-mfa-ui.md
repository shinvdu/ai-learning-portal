## 目标

提供账户状态、修改密码与 MFA 自助管理。

## 行为与范围

- 显示验证状态、角色、MFA 状态。
- 修改密码需当前密码。
- MFA 设置展示 secret/otpauth URI，启用后一次性展示恢复码。
- 停用 MFA 需密码。

## 验收标准

- [ ] 启用 MFA 后下次登录需挑战。
- [ ] 恢复码可登录且单次有效。
- [ ] 修改密码撤销其他会话。
- [ ] 密钥可被常见验证器识别。
